# 복장 설계법

## 1. 설계 순서
1. **상황을 정한다**: 어디서, 무엇을 하는가. 예) 비 오는 항구에서 화물 검수, 왕궁 연회, 숙소에서 쉬는 밤
2. **캐릭터를 반영한다**: 직업·성격·세계관의 기술 수준·계절·신분이 옷에 드러나게 한다.
3. **실루엣을 하나 고른다**: A라인, H라인(일자), X라인(허리 강조), 오버사이즈 상의+슬림 하의, 레이어드
4. **색을 2~3개로 정한다**: 주색 1, 보조색 1, 포인트색 1. 머리색과 옷의 주색은 겹치지 않게 하거나, 겹치면 음수 가중치나 UC로 번짐을 막는다.
5. **소재를 정한다**: 상황에 맞는 소재(전투=가죽·금속, 연회=새틴·벨벳, 일상=면·니트)
6. **디테일 1~2개**만 문장으로 강조한다. 디테일이 많으면 모두 흐려진다.

## 2. 태그 쓰는 순서 (커뮤니티 팁, arca.live/b/aiart/159947900)
장르 → 소재 → 구조 → 상의 → 아우터 → 하의 → 레그웨어 → 신발 → 머리 장식 → 액세서리

- 옷마다 앞에 색을 붙인다: `white collared shirt, black waistcoat, grey trench coat, open coat`
- 열린 아우터는 `open jacket`, `open coat`로 쓴다.
- 레이어를 자연어로 보강한다: `the waistcoat is worn over the shirt and under the open coat`

## 3. 색 번짐 막기 (커뮤니티 팁)
- 옷마다 색을 따로 붙인다.
- 머리색이 옷으로 번지면 그 색 조합을 UC에 쓰거나 본문에 `-1::pink dress ::`처럼 넣는다.
- 한 문장에 한 옷만 묘사한다.
- (참고) `flat color`, `limited palette`로 색을 묶는 팁도 있지만 그림체 태그라서 **이 스킬은 쓰지 않는다.**

## 4. 상황별 복장 틀
요청이 넓으면 서로 다른 축에서 2~3벌을 고른다. 모두 오리지널로 조합한다.

| 상황 | 뼈대 | 바꿀 축 |
|---|---|---|
| 일상 외출 | 니트·셔츠 + 코트·카디건 + 스커트·바지 + 부츠·로퍼 | 계절, 격식 정도 |
| 업무·직장 | 셔츠 + 조끼·재킷 + 슬랙스·펜슬 스커트 | 업종(연구, 사무, 현장), 세계관 시대 |
| 전투·모험 | 이너 + 부분 갑옷·가죽 + 망토 + 전투화 + 벨트·파우치 | 무기 종류, 기동성 vs 방어 |
| 연회·정장 | 드레스·턱시도 + 장갑 + 장신구 | 문화권, 신분, 노출 정도 |
| 휴식·잠옷 | 루즈한 셔츠·가운·니트 + 맨발·슬리퍼 | 실내 온도, 소재 |
| 전통·민속 | 한복, 기모노, 치파오, 던들 등 + 현대·판타지 변형 | 고증 vs 퓨전 |
| 운동·활동 | 크롭 탑·저지 + 쇼츠·레깅스 + 운동화 | 종목 |
| 계절 | 여름=민소매·린넨·샌들 / 겨울=패딩·퍼 트림·목도리 | 날씨 연출 |

## 5. 패션 스타일 키워드 (핀터레스트 검색어로도 쓴다)
techwear, gorpcore, cyberpunk, military-inspired, utility wear, workwear, gothic lolita, classic lolita, Victorian, Rococo, steampunk, dark academia, preppy, punk, grunge, boho, ballet-core, mori kei, visual kei, Harajuku decora, Y2K, streetwear, minimalist, avant-garde, modern hanbok, qipao, wa-lolita

스타일 이름은 태그로 잘 안 먹을 수 있다. 스타일을 **구성 요소로 풀어서** 쓴다.
예) techwear → `black cargo pants, multiple straps, buckles, black hooded jacket, waterproof fabric, utility belt`

## 7. 핀터레스트 활용
- 검색어 예: "[스타일] outfit flat lay", "[스타일] fashion illustration", "garment technical flat", "costume design turnaround", "character outfit reference sheet"
- 이미지에서 얻은 것은 **실루엣·소재·구조·색 배치**로 바꿔 문장에 쓴다.
- 특정 작품 캐릭터의 팬아트나 공식 일러스트는 참고하지 않는다(오마쥬 금지).
