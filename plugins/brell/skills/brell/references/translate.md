# 에덴 언어 판본 번역·최신화 (영문·일본어·중국어 번체)

한국어 원문을 기준으로 에덴의 English·日本語·中文（繁體） 판본을 갱신한다. 편집창 조작은 `sites/eden.md`도 같이 읽는다.

## 0. 절대 원칙

- **자동번역 금지.** 편집 화면의 '자동 번역' 버튼은 누르지 않는다. 번역은 Claude가 직접 한다.
- **명령어도 그 언어로.** `!출장` 같은 한국어 명령어를 외국어판에 남기지 않는다. 외국어판은 그 언어 사용자가 치는 판이다. 명령어는 로어북 키워드와 작품소개에 같이 들어가므로 둘을 같은 값으로 맞춘다.
- **범위 = 최신화.** "영문판/일본판/중국판 해 줘", "최신화해 줘"는 메인 프롬프트 + 로어북 전체 + 작품소개(제목·부제목 포함)를 최신 한국어판 기준으로 다시 번역해 덮어쓴다는 뜻이다. 시작 상황·캐릭터 설정은 제작자가 말할 때만 한다. 작품소개만 언급해도 메인·로어북이 낡았으면 그 사실을 알리고 같이 할지 한 번만 묻는다.
- **단어 순화 금지는 번역에도 적용.** 원문의 직설어는 대상 언어의 같은 수위 단어로 옮긴다. 예) 자지 → cock / チンポ / 雞巴, 보지 → pussy / マンコ / 屄. 肉棒·小穴 같은 완곡어로 바꾸지 않는다.
- 교차검증(미성년자·실존인물)은 번역 중에도 같이 본다.

## 1. 순서

1. **원문 확보**: `GET /api/works/{id}`로 `scenario_settings`·`lorebook[]`·`description`·`title`·`subtitle`을 읽는다(읽기만).
2. **기존 판본 용어집 만들기**: 각 판본 편집창(`?language=en|ja|zh-TW`)의 로어북에서 캐릭터 이름·명령어·모드 이름을, 메인에서 앱 이름·장소·지역 이름을 뽑는다. **기존 판본의 표기를 그대로 쓴다.** 새로 생긴 것(예: 새 모드의 명령어)만 새로 만든다.
3. **번역**: 줄 구조·기호(`¶`, `|`, `·`, `=`, `<<이름>>`, `{{user}}`, `[//]: # (...)`, 코드펜스)를 그대로 두고 내용만 옮긴다. 이미지·SVG 주소는 서버 주소를 원문 그대로 두고 `{코드1}` 같은 자리표시만 번역한다. 캐릭터 코드(M01…)·상황 코드 숫자·파라미터 이름(code, tier, u, c, n, m1…)은 바꾸지 않는다.
4. **판본별로 넣기 → '번역 저장'** (2절).
5. **검증**: 판본을 다시 열어 메인·로어북 25개(제목·키워드·내용)·작품소개가 넣은 값과 정확히 같은지 비교. 작품소개에 한글이 남았는지 확인(이미지 주소 안 제외). 한국어 원문 `status`·`visibility`가 그대로인지 확인.
6. **보고**: 판본별로 바뀐 것, 언어별 명령어 표, 유지한 표기, 손대지 않은 것(시작 상황, 이미지 속 한국어 대사 등).

## 2. 에덴 판본 편집 요령

- 판본 전환은 상단 '언어 판본 선택' → 언어, 또는 `/edit-work/{id}?language=en|ja|zh-TW`. 전환하면 페이지가 새로 뜨므로 `window` 변수가 사라진다. 판본 사이에서 들고 다닐 데이터는 같은 도메인 `localStorage`에 둔다(`__brell_` 접두어, 끝나면 삭제).
- 넣기 전에 화면 문구 "○○ 판본을 편집하고 있습니다"로 판본을 확인한다.
- **메인·작품소개**: 입력칸 fiber 위쪽 props에서 `setValue`·`getValues`를 가진 폼 객체를 찾아 `setValue('scenario_settings'|'title'|'subtitle'|'description', 값, {shouldDirty:true, shouldTouch:true})`.
- **로어북**: '로어북' 탭에서 `setLorebook`을 가진 상태 객체를 찾는다. 기존 항목의 `id`는 같은 순번에서 유지하고 `title`·`keywords`·`content`를 바꾼다. `triggerMode`·`turnRange`·`offKeywords`·`offTurnRange`는 한국어 원문 값과 맞춘다. `setEditingLorebook({})` 후 `setLorebook(새배열)`. 오른쪽 편집칸이 새 값으로 보이는지 확인하고 저장한다.
- **작품소개 HTML**: 원문을 태그 기준으로 나눠(`split(/(<[^>]*>)/)`) `<style>` 밖의 한글 텍스트 조각만 번역 조각으로 바꾸고 다시 이어 붙인다. 태그·CSS·이미지 주소는 건드리지 않는다. `alt`·`aria-label`의 한글도 번역한다. 앞뒤 공백·`&nbsp;`·`&lt;` 같은 엔티티를 보존한다.
- **저장**: '번역 저장' 버튼. 누르면 `/my-works`로 이동하고 "○○ 판본을 저장했습니다"가 뜬다. 판본 저장은 한국어 원문을 비공개로 바꾸지 않지만 원문 `updated_at`은 갱신된다. 보고에 적는다.
- 판본 내용이 바뀌면 원문 쪽 '임시저장'·'작품 게시'는 누르지 않는다.

## 3. 브라우저로 큰 글 옮기기

- JS 출력에 `=`, `?`, `&`, URL이 섞이면 차단된다. 원문 읽기는 같은 도메인 `/robots.txt` 새 탭에서 `fetch`한 값을 `<pre>`에 넣고(URL은 `[URL]`, `=?&`는 전각으로) 페이지 텍스트로 읽는다. 작은 조각은 1,300자 안팎씩 나눠 출력한다.
- 번역문을 넣을 때는 ``String.raw`…` `` 리터럴로 `localStorage`에 저장한다. 내용 속 백틱은 `⟦BT⟧`로 적고 넣기 직전에 되돌린다. 이미지 주소의 서버 자리는 `[HOST]`로 적고, 원문에서 뽑은 서버 주소를 등장 순서대로 끼운다(메인과 디버그 로어북은 순서가 다르니 각각 뽑는다).
- 한 번에 15,000자 안팎으로 나눠 보낸다. 받은 뒤 글자 수(코드포인트)를 로컬 원고와 대조한다.
- 로어북 원고 형식: `=====TITLE: 제목` / `=====KEYS: 키1 | 키2` / 내용. 25개가 다 파싱되는지 확인한다.

## 4. 용어·키워드 기준

- 캐릭터 로어북 키워드: `<<이름>>`, 이름, 이름(성 뺀 것), `code=M01`. 한국어처럼 조사 붙은 형태는 만들지 않는다.
- 모드 로어북 키워드: 명령어, 모드 이름, 숫자 이모지(예: `1️⃣`, `1⃣`).
- 명령어 예시(이 작품 기준): 출장 !trip/!出張/!出差 · 반지 !ring/!指輪/!戒指 · 커스텀 !custom/!カスタム/!自訂 · 난교 !orgy/!乱交/!亂交 · 갱뱅 !gangbang/!ギャングバン/!群P · 세이브 !save/!セーブ/!存檔 · 로드 !load/!ロード/!讀檔 · 디버그 !debug/!デバッグ/!除錯. "!디버그 취소"는 cancel/取消.
- 커스텀 모드의 "시작" 같은 진행어도 번역한다(Start/開始/開始).
- 작품소개 예시 이미지가 주소에 한국어 대사를 담고 있으면 그대로 두고 보고에 적는다. 바꾸려면 제작자에게 먼저 묻는다(이미지 서버가 해당 언어 글꼴을 지원하는지 모름).
