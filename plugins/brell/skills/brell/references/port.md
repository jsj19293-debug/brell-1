# 다른 플랫폼 이식

에덴 원본(또는 제작자가 정한 원본)을 다른 사이트 양식으로 옮긴다. 한도는 SKILL.md 「사이트 규격」 표, 편집창 조작은 `sites/` 안의 해당 사이트 파일. 원본 플랫폼 쪽은 읽기만 하고, 조사용 탭은 새로 열어 끝나면 닫는다.

## 1. 순서

1. **양쪽 전문 확보**: 원본(메인·로어북·캐릭터·시작 상황)과 대상 편집창의 현재 상태. 제작자가 주는 자료(홈페이지 HTML, 연표 등)도 읽는다.
2. **매핑표 보고**: 원본의 메인·로어북·캐릭터·시작 상황이 대상의 어디로 가는지, 한도 때문에 못 들어가는 것, 항목별 현재 글자 수와 한도. 대상에 이미 이식본이 있으면 빠진 것을 "꼭 필요 / 일부러 뺐을 수 있음 / 안 옮긴 로어북"으로 나눈다.
3. 승인 → 메인 → 로어북(모드 → 캐릭터 → 게이트 → 세계관 → 장소) → 시작 상황 순으로 넣는다.
4. 이식본에도 `audit.md` 2절 검수를 한 번 돌린다.
5. 검증(우마이는 로어북 테스트) → 보고.

수정은 정확한 문자열 치환, 치환마다 일치 횟수 확인, 어긋나면 반영하지 않는다. 덮어쓰기 전에 원본을 `window`에 보관한다.

## 2. 압축 우선순위

원문에 최대한 가깝게 두고 한도를 넘는 것만 줄인다.

1. **원문 유지**: 절대규칙, INFO 양식, 이미지 출력형식.
2. **형식 유지**: 캐릭터 DB 한 줄 형식.
3. **마지막에 넣거나 뺌**: 편의 기능(SNS·갤·방송) → 부가 모드 → 세력 설명 → 관계도 순으로 먼저 뺀다.

**압축 중 지어내기 금지**: 압축은 원문에 있는 내용을 줄이기만 하는 작업이다. 원문에 없던 사실·관계·설정을 새로 넣지 않는다.
- 예) 원문 1,000자 로어북의 "A와 B는 가족이다"를 500자로 줄이면서 "A와 B는 가족이지만 사실 의붓가족이다"로 바꾸면 지어낸 것이다. "A와 B는 가족"까지만 남긴다.
- 줄이다가 뜻이 바뀌거나 애매해지면 줄이지 말고 원문 문장과 줄인 안을 같이 보여 주며 묻는다.
- 이 규칙은 압축(이식)에만 해당한다. 제작자가 요청한 세계관 보강·추가 설정은 `[창작]`으로 표시해 따로 낸다.

무엇을 줄이고 뺐는지 목록으로 보고한다. 종량제(우마이·엘린)는 한도가 넉넉해도 메인을 얇게 두고 나머지를 로어북으로 뺀다.

## 3. 변환 규칙

- **대사양식·캐릭터 키**: 규격표의 대사양식으로 바꾼다. 캐릭터 키는 `**이름`(챗플·바베·루나·엘린·우마이), `@이름@`(젠잇), `<<이름>>`(에덴). 에덴 외에는 메인에 그 사이트의 대사양식 줄을 넣는다.
- **키워드 개수**: 규격표대로(에덴·우마이 7개, 나머지 5개).
- **완전일치(챗플)**: `!X`로 `!!X`를 못 잡으므로 표기별로 키를 따로.
- **끄는 키워드가 없는 곳**: 모드 겹침을 본문 규칙으로 막는다.
- **동시 적용 제한(바베 기본 5개)**: 중요한 항목을 위로.
- **루나**: 로어북은 별개 객체라 따로 만들어 캐릭터에 연결한다.
- **챗플**: 캐릭터를 개별 등록 칸(설명 1,000자)에 넣는다.

## 4. 우마이 세부

우마이는 종량제이고 부분일치이며, 직전 AI 응답과 보낼 메시지를 검색한다(로어북 테스트로 확인).

**로어북**
- 모드 항목은 목록 맨 위. 첫 줄 `🎭 모드이름 | 이모지` + "INFO 모드란에 매 턴 그대로 유지", `## 과거 배경 / ## 현재 배경 / ## 관계 / ## 시작` 틀, 1,000~1,500자, 본문 표기 `{{user}}`.
- 모드 키는 INFO에 찍히는 형태(`🎭 폐급모드`, `| 💀`) + 명령어(`!!폐급모드`). 게이트는 `게이트색상:(🟡)`.
- 세계관(연표·세력사)은 물어볼 때만 켜지게 질문에 나올 단어를 키로.
- "인트로에서도 활성화"는 전부 끈다.
- 키워드 7개 이하, 본문 1,000~1,500자.

**인트로 (시작 설정)**
- 구성: 이미지 → `[//]: # (...)` 주석 → 입력 안내와 예시 → INFO 상태창(코드블록).
- 주석에는 그 모드의 핵심 사실과 "첫 응답은 어느 장면부터 이어서 시작"을 적는다(인트로 활성화를 끄면 첫 턴에 모드 로어북이 안 켜질 수 있어서). 주석 안에는 괄호를 쓰지 않는다.
- 웹툰·이미지 프롤로그는 직접 보고 장면과 대사를 주석으로 옮긴다.
- 입력 예시에 모드 명령어: `EX) !!일반모드 / 남자 / 파이어볼 / E 등급 / 지구`.
- 상태창 유저 칸: `👤{{user}} | 성별(입력) | 이능(입력) | 등급(입력) | 출신(입력)`.
- 대사는 `" **이름 |** 대사"`, 대사 위에 이미지 한 줄.
- **여러 모드를 고르는 인트로**: 명령어를 `!!**헬모드**`처럼 써서 키와 일치하지 않게 하고, 설명 줄에 캐릭터 이름을 쓰지 않는다. 상태창은 "선택 대기" 틀, 주석에 "첫 응답에서 실제 값으로 바꾼다".

**검증**: `lorebook.md` 7절 발동 테스트를 우마이 로어북 테스트(`sites/uumai.md`)로 돌린다.

**보고 추가 사항**
- 남은 충돌(메인과 모드의 호감도 범위 등)은 해결될 때까지 매번 짧게 적는다.
- 토큰은 편집창 표시값을 쓴다. 로어북은 `자 × 약 0.76` 추정치임을 밝힌다.
