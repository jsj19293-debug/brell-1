# 시작상황 · 세계관 시나리오 (`/시나리오`)

제작자가 `/시나리오`를 쳤을 때만 이 파일을 쓴다. 문체는 `style.md`(쇠맛 제거)를 함께 읽고 따른다.

## 1. 받을 것

없는 것만 한 번에 묻는다. 셋이 다 있어야 시작한다.

1. **메인 프롬프트 + 로어북**
2. **등장인물**: 제작자가 등장시키고 싶은 캐릭터
3. **만들 것**: 시작상황 / 세계관 시나리오 중 하나

## 2. 제작 준비

1. 메인 프롬프트와 로어북을 전부 읽고 세계관을 파악한다: 장르, 시점, {{user}}의 위치, 세력, 장소, 등장인물끼리의 관계. 읽다가 모순이나 결함이 보이면 표시해 두고 보고에서 `/검수`를 권한다.
2. 이 세계관과 닮은 웹소설·웹툰·소설·글을 인터넷에서 검색해 참조한다(`style.md` 1부). 배우는 것은 장르의 리듬과 장면 처리 방식이다. 문장, 설정, 고유명사, 캐릭터는 가져오지 않는다.
3. 메인·로어북에 없는 사실은 새로 만들지 않는다. 장면에 꼭 필요해서 새로 지은 것은 보고의 "제가 정한 것"에 `[창작]`으로 적는다.

## 3-A. 시작상황

- **사이트**: 우마이와 에덴 두 벌을 만든다. 글자 수는 규격표의 시작상황(우마이 5,000 / 에덴 5,000)이 상한이다. 지루하지 않게 필요한 만큼만 쓴다.
- **구성**: 장면(장소·시간·누가 있는지) → 등장인물의 행동과 대사 → {{user}}에게 넘기는 지점에서 끊는다 → INFO 첫 출력(메인 INFO 양식 그대로).
- {{user}}의 대사·행동·속마음은 쓰지 않는다.
- 대사는 규격표의 대사양식을 따른다. 모드 명령어가 들어가면 `!!**일반**모드`처럼 끊어 써서 로어북 키를 건드리지 않게 한다(`lorebook.md` 4절).
- **우마이 양식**: `port.md` 4절 「인트로」 구성을 따른다.
- **에덴 양식**: 위 공통 구성을 그대로 쓰고, 규격표의 에덴 기준(시작상황 5,000자, 대사양식 `<<이름>>` 자동 출력)을 따른다. 대사는 `<<이름>>` 표기로 쓴다.

## 3-B. 세계관 시나리오

메인 프롬프트나 로어북에 들어가지 않는 글이다. 용도는 둘이다: 작품의 **서사 목록**, 그리고 나중에 이용자가 즐길 콘텐츠를 미리 보여 주는 **눈요기 거리**.

1. **한 줄 소개**: 이 세계에서 {{user}}가 무엇을 겪게 되는지 한 문장.
2. **서사 목록**: 벌어질 수 있는 사건을 하나씩. 사건마다 누가, 무엇을 원하는데, 무엇이 막는지를 3문장 이내로 쓴다. 결말은 정리하지 않는다.
3. **눈요기 거리**: 이용자가 직접 해 볼 수 있는 것을 한 줄씩. 만날 수 있는 인물 조합, 가 볼 수 있는 장소, 끼어들 수 있는 사건, 숨어 있는 요소.

- 항목은 짧게 끊는다. 설정 설명문이 아니라 읽고 싶어지는 글로 쓴다.
- 메인·로어북과 어긋나지 않게 쓰고, 새로 지은 사건·장소는 `[창작]` 표시한다.

## 4. 보고

1. 결과물: 코드블록. 시작상황은 우마이·에덴 따로.
2. 글자 수: 실제로 재서 적는다. 규격표 상한과 같이 적는다.
3. 제가 정한 것: `[창작]` 항목 목록.
4. 참조: 검색해서 참조한 작품의 제목과 링크. 결과물 본문에는 넣지 않는다.
5. 확인 필요: 메인·로어북에서 보인 모순, 방향 선택이 필요한 것.
