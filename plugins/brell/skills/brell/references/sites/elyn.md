# 엘린

## 주소·로그인
- `https://elyn.ai`
- `https://elyn.ai/login` → 'Google로 계속하기'.

## 편집화면 진입
- 프로필 사진 → 마이페이지(`/my-page`) → '캐릭터' 목록 카드 링크(`/characters/{id}`)에서 id → `/edit-character/{id}`.
- 탭 제목이 '엘린 - {제목}'이면 맞다.

## 탭 구성
- 오른쪽 패널: 기본 정보 · 갤러리 · 상세 설정(메인) · 로어북 · JSX 스크립트.
- 왼쪽은 테스트 채팅이니 글자를 읽을 때 섞지 않는다.

## 누르지 않는 것
- 로어북 줄 오른쪽 끝 X(삭제).
