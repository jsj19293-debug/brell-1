# 사이트 공통 (브라우저)

사이트 파일을 읽을 때 이 파일도 같이 읽는다.

- 크롬(Claude in Chrome)에서 한다. 첫 브라우저 동작 전에 크롬 스킬을 읽는다.
- "(사이트) 열어줘"는 그 사이트 파일만 읽고 그 사이트만 연다. "전체 열어줘"면 7개 사이트 파일을 차례로 쓰고, 여러 탭 동작은 한 묶음 호출로 처리한다.
- 탭 목록을 먼저 조회한다. 이미 열린 사이트·편집화면은 그대로 쓴다. 다른 작품 편집화면이 열린 탭은 옮기지 않고 새 탭을 쓴다.
- 로그인은 계정 선택 화면에서 제작자 계정을 고르는 데까지만 한다. 새 권한 동의 화면은 누르기 전에 묻는다. 취향 선택·알림·쿠키 팝업은 설정을 바꾸지 않는 '닫기'만 누른다.
- 작품 제목은 목록에서 글자를 대조해 고르고, 들어간 뒤 이름 칸이나 탭 제목으로 한 번 더 확인한다. 비슷한 제목이 여럿이면 들어가지 말고 후보를 보여 주며 묻는다. 제작자는 줄임말을 쓴다(「3차원 아카데미의 재수생」 = 삼아카).
- 편집화면은 들어가는 데서 끝내고 내용은 건드리지 않는다. 탭 전환은 탭을 눌러서 하고 '다음' 버튼은 쓰지 않는다.
- 화면이 아래 설명과 다르면 화면에서 찾아 진행하고, 달라진 점을 보고 끝에 "스킬 갱신 필요"로 적는다.

## 편집창 읽기 요령

- 브라우저 JS 도구 출력은 약 1,000자에서 잘린다. 긴 본문은 `window` 변수에 넣고 900자씩 나눠 읽거나, 같은 도메인의 `/robots.txt`를 새 탭으로 열어 `<pre>`에 4만 자씩 넣고 페이지 텍스트로 읽는다. 임시 탭은 끝나면 닫는다.
- 출력에 URL이나 `=`, `?`, `&`가 섞이면 차단된다. URL은 `[URL]`로, `=`→`＝`, `?`→`？`, `&`→`＆`로 바꿔 출력한다.
- 화면 구조 파악은 입력칸 목록(종류·현재 길이·최대 길이·안내 문구)만 뽑는 스크립트로 한다.
- 외부 이미지 확인: 주소가 `{저장소}/{코드}/{번호}.png` 형태면 새 탭에서 한 장을 연 뒤 같은 도메인에서 8장씩 격자로 띄워 본다. 존재 확인은 HEAD 대신 `Image()` 로드로 한다(CORS).
