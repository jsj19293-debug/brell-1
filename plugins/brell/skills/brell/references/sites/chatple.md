# 챗플

## 주소·로그인
- `https://ko.chatple.live`
- 오른쪽 위 프로필 아이콘 → 로그인 창까지만 띄운다. 구글(G) 버튼은 제작자가 누른다(팝업 방식이라 Claude가 눌러도 반응 없음).

## 편집화면 진입
- `/profile` → '제작 캐릭터' 카드 링크(`/content/{번호}`) → `/studio/{번호}/edit`.
- '크리에이터 편집'(프로필 수정)과 왼쪽 제작 아이콘(새 캐릭터 등록)은 편집화면이 아니다.
- '이어서 수정하기' 창(임시저장본 목록)이 뜨면 아무것도 고르거나 지우지 않고 목록(이름·저장 시각)을 보고한다. 탭을 읽어야 하면 오른쪽 위 X로 창만 닫고(임시저장본은 남는다) 닫았다고 보고한다.

## 탭 구성
- 프로필 · 배경 설정(메인 + 캐릭터 개별 등록) · 도입부(시작상황) · 캐릭터 에셋 · 메모리북(로어북) · 기타 설정.
- 메모리북 키워드는 정확히 일치해야 반영된다.

## 누르지 않는 것
- '수정 완료'.
