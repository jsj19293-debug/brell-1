## 메인 작성 금지사항

- 메인에 로어북을 가리키는 지시를 쓰지 않는다. 예) "로어북에서 읽는다", "로어북의 성격을 따른다", "[로어북 이름]에만 있다". 플랫폼마다 AI가 '로어북'이라는 단어를 알 수 없다. 메인은 메인만으로 동작하게 쓴다.
- 이미 적힌 내용을 다른 문장으로 다시 쓰지 않는다. 모든 내용을 자연어로 풀어 쓰지 않는다.
- 정의하지 않은 약어·기호를 쓰지 않는다.
- 제작자가 말하지 않은 형식·규칙을 지침으로 만들지 않는다.
- 글자 수는 실제로 재서 보고한다.
